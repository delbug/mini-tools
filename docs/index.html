DeskKit

本地小工具集：多文件夹对比与同步、语雀批量导出、Confluence 粘贴用 HTML、重复文件检测等。 数据保存在本机，无需上传云端。

下载桌面版 GitHub 源码 使用文档

功能模块

文件夹对比

MD5 / 路径对比，主辅同步、并集、删除与移动。

语雀导出

Token 批量导出知识库，可选 Markdown / Confluence 网页 HTML。

Confluence 转换

Markdown 转 HTML / Word / PDF，浏览器复制粘贴保留图片。

重复文件

递归扫描目录，按 MD5 找出重复项。

批量重命名

前缀后缀、替换、序号、清理非法字符。

收藏管理

保存常用文件夹组合，刷新后自动恢复。

开发者 / 命令行启动

  1. 安装 Node.js LTS
  2. git clone https://github.com/delbug/mini-tools.git && cd mini-tools
  3. npm install && npm run boot
  4. 浏览器打开 http://localhost:3457（端口被占用时会自动换端口）

打包桌面版见仓库内 README-DESKTOP.md。
